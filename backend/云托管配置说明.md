# 微信云托管配置说明

云托管公网地址：`https://springboot-mezu-226383-7-1405114852.sh.run.tcloudbase.com`

## 一、云托管控制台需配置的环境变量

在 **服务 → 版本配置 → 环境变量** 中添加：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `SPRING_PROFILES_ACTIVE` | `cloud` | 激活 cloud 配置 |
| `MYSQL_ADDRESS` | `<YOUR_MYSQL_HOST>:3306` | 外网 MySQL 地址 |
| `MYSQL_USERNAME` | `root` | 数据库用户名 |
| `MYSQL_PASSWORD` | `<YOUR_MYSQL_PASSWORD>` | 数据库密码 |

### Redis 配置（如云托管有 Redis 或使用腾讯云 Redis）

| 变量名 | 值 |
|--------|-----|
| `REDIS_HOST` | Redis 主机（如提供） |
| `REDIS_PORT` | `6379` |
| `REDIS_PASSWORD` | 密码（无则留空） |

> **说明**：当前后端依赖 Redis（用于缓存微信 access_token）。若云托管未提供 Redis，需在腾讯云创建 Redis 实例，或后续改造为可选依赖。

## 二、小程序端配置

已在 `app.js` 中配置云托管 API 地址：

```javascript

```


## 三、快速验证

部署成功后，在浏览器访问：

```
https://springboot-mezu-226383-7-1405114852.sh.run.tcloudbase.com/api/user/login
```

若返回 JSON（如 `{"code":400,...}` 或 `{"code":200,...}`），说明后端已启动并可访问。

## 四、云环境配置说明（application-cloud.yml）

- **数据库**：使用环境变量 `MYSQL_ADDRESS` / `MYSQL_USERNAME` / `MYSQL_PASSWORD`
- **上传目录**：`uploads/chat`、`uploads/goods`、`uploads/avatar`（相对路径）
- **AI 对话**：使用 `mock` 模式（云上无 Ollama）

## 五、自我奖励商品图片 404 问题

若云托管上自我奖励图片 404，需将图片打包进 jar：

1. 将图片放入 `images/goods/self-reward/`，命名为 `reward_1.png`～`reward_6.png`
2. 运行 `backend\database\run_import_goods_images.bat`
3. 脚本会复制到 `backend/uploads/goods/` 和 `backend/src/main/resources/static/uploads/goods/`（后者会打进 jar）
4. 重新构建并部署云托管
