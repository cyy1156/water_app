# 解决 Maven 依赖下载问题

## 🔴 当前问题

IDE 显示多个错误：
- ❌ 无法解析符号 'mybatis'
- ❌ 无法解析符号 'springframework'
- ❌ 无法解析符号 'SpringBootApplication'
- ❌ 无法解析符号 'MapperScan'
- ❌ 无法解析符号 'SpringApplication'

**原因**：Maven 依赖没有下载，导致 IDE 无法识别这些类。

---

## ✅ 解决步骤

### 步骤1：确保 JDK 已配置

1. **检查 JDK 配置**
   - File → Project Structure（`Ctrl + Alt + Shift + S`）
   - 确认 "Project SDK" 已选择 JDK 1.8 或更高版本
   - 如果没有，先配置 JDK（见"配置JDK和Maven指南.md"）

### 步骤2：手动触发 Maven 下载依赖

#### 方法A：使用 Maven 工具窗口（推荐）

1. **打开 Maven 工具窗口**
   - 点击右侧边栏的 **"Maven"** 图标
   - 或 View → Tool Windows → Maven
   - 如果看不到，点击右侧边栏的任意图标，找到 Maven

2. **刷新项目**
   - 在 Maven 工具窗口中，找到项目名称 `water-app`
   - 右键点击项目名称
   - 选择 **"Reload project"**（重新加载项目）

3. **等待下载**
   - IDE 右下角会显示进度条
   - 显示 "Downloading..." 或 "Indexing..."
   - 首次下载需要 3-10 分钟，请耐心等待

#### 方法B：使用 Maven 生命周期

1. **打开 Maven 工具窗口**
   - 点击右侧边栏的 "Maven" 图标

2. **展开项目结构**
   - 展开 `water-app`
   - 展开 `Lifecycle`

3. **执行 install**
   - 双击 **"install"**
   - 这会触发 Maven 下载所有依赖并编译项目

4. **查看输出**
   - 在底部会打开 "Run" 窗口
   - 可以看到下载进度和编译过程

#### 方法C：使用命令行

1. **打开终端**
   - 在 IDE 底部点击 "Terminal" 标签
   - 或 View → Tool Windows → Terminal

2. **进入项目目录**
   ```bash
   cd backend
   ```

3. **执行 Maven 命令**
   ```bash
   mvn clean install
   ```
   或
   ```bash
   mvn dependency:resolve
   ```

4. **等待完成**
   - 会显示下载进度
   - 完成后，IDE 会自动识别依赖

---

### 步骤3：验证依赖是否下载成功

#### 检查方法1：查看 Maven 工具窗口

1. 打开 Maven 工具窗口
2. 展开项目 → Dependencies
3. 应该能看到所有依赖包，如：
   - spring-boot-starter-web
   - mybatis-plus-boot-starter
   - mysql-connector-java
   - 等等

#### 检查方法2：查看代码错误

1. 等待下载完成后
2. 查看 `WaterAppApplication.java`
3. 红色错误应该消失
4. 导入语句不应该有红色波浪线

#### 检查方法3：查看 Event Log

1. 点击 IDE 右下角的通知图标 🔔
2. 查看是否有 "Maven" 相关的成功通知
3. 或查看是否有错误信息

## 🔧 如果仍然无法下载

### 问题1：网络问题

**解决方法**：配置 Maven 镜像（使用国内镜像加速）

1. **打开 Maven 设置**
   - File → Settings → Build, Execution, Deployment → Build Tools → Maven

2. **找到 settings.xml**
   - 点击 "User settings file" 旁边的文件夹图标
   - 如果没有，创建一个

3. **添加阿里云镜像**
   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <settings xmlns="http://maven.apache.org/SETTINGS/1.0.0"
             xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
             xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.0.0
             http://maven.apache.org/xsd/settings-1.0.0.xsd">
       <mirrors>
           <mirror>
               <id>aliyun</id>
               <mirrorOf>central</mirrorOf>
               <name>Aliyun Maven</name>
               <url>https://maven.aliyun.com/repository/public</url>
           </mirror>
       </mirrors>
   </settings>
   ```

4. **保存并重新加载项目**

### 问题2：Maven 未配置

**解决方法**：

1. **检查 Maven 配置**
   - File → Settings → Build, Execution, Deployment → Build Tools → Maven
   - 确认 "Maven home path" 已配置
   - 如果没有，使用 IDEA 内置的 Maven（通常已配置好）

2. **使用 IDEA 内置 Maven**
   - 在 Maven 设置中
   - 选择 "Bundled (Maven 3)" 或类似选项

### 问题3：项目未识别为 Maven 项目

**解决方法**：

1. **右键项目根目录**
   - 在项目资源管理器中，右键 `backend` 文件夹

2. **添加为 Maven 项目**
   - 选择 "Add Framework Support..."
   - 勾选 "Maven"
   - 点击 OK

## 📋 完整操作流程

### 第一次打开项目

1. **打开项目**
   - File → Open → 选择 `D:\小程序\backend`

2. **配置 JDK**（如果未配置）
   - File → Project Structure
   - 配置 Project SDK

3. **打开 Maven 工具窗口**
   - 点击右侧边栏的 Maven 图标

4. **重新加载项目**
   - 右键项目 → Reload project
   - 或点击刷新按钮 🔄

5. **等待下载**
   - 查看右下角进度条
   - 首次需要 3-10 分钟

6. **验证**
   - 查看代码错误是否消失
   - 查看 Maven 工具窗口中的 Dependencies

## ⏱️ 下载时间

- **首次下载**：3-10 分钟（取决于网络速度）
- **后续打开**：几秒钟（依赖已缓存）

## ✅ 成功标志

下载成功后，你应该看到：

1. **代码错误消失**
   - `WaterAppApplication.java` 中没有红色错误
   - 导入语句正常

2. **Maven 工具窗口**
   - Dependencies 下显示所有依赖包
   - 没有错误提示

3. **可以运行项目**
   - 右键 `WaterAppApplication.java`
   - 可以看到 "Run 'WaterAppApplication'" 选项
