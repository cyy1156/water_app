# 后端项目运行指南

## 🚀 快速启动

### 方法一：使用IDE运行（推荐，最简单）

#### IntelliJ IDEA

1. **打开项目**
   - 打开 IntelliJ IDEA
   - File → Open → 选择 `D:\小程序\backend` 文件夹
   - 等待Maven自动下载依赖（首次需要几分钟）

2. **找到启动类**
   - 在项目结构中，找到 `src/main/java/com/waterapp/WaterAppApplication.java`

3. **运行项目**
   - 右键点击 `WaterAppApplication.java`
   - 选择 `Run 'WaterAppApplication'`
   - 或点击类名旁边的绿色运行按钮 ▶️

4. **查看启动日志**
   - 在控制台（Console）中查看日志
   - 看到以下内容说明启动成功：
     ```
     Tomcat started on port(s): 8080 (http) with context path '/api'
     Started WaterAppApplication in X.XX seconds
     =================================
     喝水健康陪伴小程序后端启动成功！
     =================================
     ```

#### Eclipse

1. **导入项目**
   - File → Import → Maven → Existing Maven Projects
   - 选择 `D:\小程序\backend` 文件夹
   - 等待Maven下载依赖

2. **运行项目**
   - 找到 `WaterAppApplication.java`
   - 右键 → Run As → Java Application

#### VS Code

1. **安装扩展**
   - 安装 "Extension Pack for Java"
   - 安装 "Spring Boot Extension Pack"

2. **打开项目**
   - File → Open Folder → 选择 `D:\小程序\backend`

3. **运行项目**
   - 找到 `WaterAppApplication.java`
   - 点击类名上方的 "Run" 按钮

### 方法二：使用命令行运行

#### 前提条件

1. **安装JDK 1.8+**
   - 下载：https://www.oracle.com/java/technologies/downloads/
   - 验证：在命令行输入 `java -version`

2. **安装Maven**
   - 下载：https://maven.apache.org/download.cgi
   - 配置环境变量
   - 验证：在命令行输入 `mvn --version`

#### 运行步骤

1. **打开命令行**
   - 按 `Win + R`，输入 `cmd`，回车

2. **进入项目目录**
   ```bash
   cd D:\小程序\backend
   ```

3. **运行项目**
   ```bash
   mvn spring-boot:run
   ```

4. **等待启动**
   - 首次运行会下载依赖，需要几分钟
   - 看到 "Tomcat started on port(s): 8080" 说明启动成功

---

   - 双击 `D:\小程序\backend\启动后端.bat`

   - 脚本会自动检查环境并启动项目

## 🔍 验证服务是否启动

### 方法1：浏览器访问

打开浏览器，访问：
```
http://localhost:8080/api/user/login
```

**应该返回**：
- JSON格式的响应（即使是错误信息也说明服务已启动）
- 如果显示"无法访问"，说明服务未启动

### 方法2：使用curl命令

```bash
curl http://localhost:8080/api/user/login
```

### 方法3：查看进程

**Windows**：
```bash
netstat -ano | findstr :8080
```

**应该看到**：
```
TCP    0.0.0.0:8080    0.0.0.0:0    LISTENING    xxxxx
```

## ⚠️ 常见问题

### 问题1：端口8080被占用

**错误信息**：
```
Web server failed to start. Port 8080 is already in use.
```

**解决方法**：

**方法A：关闭占用端口的程序**
```bash
# 查找占用8080端口的进程
netstat -ano | findstr :8080

# 结束进程（替换PID为实际进程ID）
taskkill /PID xxxxx /F
```

**方法B：修改端口**
在 `application.yml` 中修改：
```yaml
server:
  port: 8081  # 改为其他端口
```

### 问题2：数据库连接失败

**错误信息**：
```
Access denied for user 'root'@'localhost'
或
Communications link failure
```

**解决方法**：
1. 检查MySQL服务是否运行
2. 检查 `application.yml` 中的数据库配置
3. 确认数据库 `water_app` 已创建
4. 确认用户名和密码正确

### 问题3：Redis连接失败

**错误信息**：
```
Unable to connect to Redis
```

**解决方法**：
1. 检查Redis服务是否运行
2. 检查 `application.yml` 中的Redis配置
3. 使用 `redis-cli ping` 测试连接

### 问题4：Maven依赖下载失败

**错误信息**：
```
Could not resolve dependencies
```

**解决方法**：
1. 检查网络连接
2. 配置Maven镜像（使用国内镜像）
3. 清理并重新下载：
   ```bash
   mvn clean install
   ```

### 问题5：编译错误

**错误信息**：
```
Compilation failure
```

**解决方法**：
1. 检查Java版本（需要JDK 1.8+）
2. 检查代码是否有语法错误
3. 在IDE中查看具体错误信息

## 📋 启动前检查清单

在运行项目前，请确认：

- [ ] JDK 1.8+ 已安装
- [ ] Maven 已安装（如果使用命令行）
- [ ] MySQL 服务已启动
- [ ] Redis 服务已启动（可选，但推荐）
- [ ] 数据库 `water_app` 已创建
- [ ] 已执行数据库初始化脚本（init.sql）
- [ ] `application.yml` 配置正确
- [ ] 端口8080未被占用

## 🛠️ 如果无法启动

### 步骤1：检查环境

```bash
# 检查Java
java -version

# 检查Maven（如果使用命令行）
mvn --version

# 检查MySQL
mysql --version

# 检查Redis
redis-cli ping
```

### 步骤2：查看详细日志

在IDE中查看控制台的完整错误信息，根据错误信息解决问题。

### 步骤3：清理并重新编译

```bash
cd D:\小程序\backend
mvn clean
mvn compile
mvn spring-boot:run
```
