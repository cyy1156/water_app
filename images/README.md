# 图片资源说明

## 文件夹结构

```
images/
├── tabbar/          # TabBar 图标（可选）
├── goods/           # 商品图片
└── common/          # 通用图片
```

## 图片资源清单

### 1. TabBar 图标（可选）

**位置**：`images/tabbar/`

**需要的图标**：
- `home.png` - 首页图标（未选中状态）
- `home-active.png` - 首页图标（选中状态）
- `calendar.png` - 日历图标（未选中状态）
- `calendar-active.png` - 日历图标（选中状态）
- `profile.png` - 我的图标（未选中状态）
- `profile-active.png` - 我的图标（选中状态）

**规格要求**：
- 尺寸：81px × 81px（推荐）
- 格式：PNG（支持透明背景）
- 颜色：未选中状态建议使用灰色（#999999），选中状态使用主题色（#2196F3）

**使用方式**：
如果需要使用图标，请在 `app.json` 的 `tabBar` 配置中添加图标路径：

```json
{
  "pagePath": "pages/home/home",
  "text": "首页",
  "iconPath": "images/tabbar/home.png",
  "selectedIconPath": "images/tabbar/home-active.png"
}
```

### 2. 商品图片

**位置**：`images/goods/`

**说明**：
- 商品图片由后端管理，存储在数据库中
- 本地图片文件夹用于存放示例图片或默认图片
- 实际商品图片应上传到服务器（OSS/CDN）

**可选示例图片**：
- `goods-default.png` - 商品默认占位图（可选）
- 其他商品示例图片

### 3. 通用图片

**位置**：`images/common/`

**说明**：
- 存放小程序中使用的通用图片资源
- 如：Logo、默认头像、占位图等

**智能体照片（首页圆环内粥粥形象）**：
- **文件名**：`agent.png`
- **路径**：`images/common/agent.png`
- **用途**：首页中心圆环内的智能体 2D 形象图（组件 `agent-shell` 引用）
- **规格建议**：透明或白底 PNG，约 380×440 像素（可等比缩放），便于在圆环内展示
- 若未放置该文件，圆环内仍会显示「粥粥说」气泡，但形象区域会留空或报图缺失；放入后即可恢复智能体照片

## 图片使用说明

### 当前代码中的图片使用

1. **个人中心封面图片**
   - 由用户上传，存储在服务器
   - 代码中已处理无图片时的占位符显示

2. **商品图片**
   - 由后端管理，存储在数据库
   - 前端通过接口获取图片URL
   - 代码中已处理无图片时的占位符显示

3. **对话图片**
   - 用户上传的图片，临时存储在本地
   - 上传后存储在服务器

### 图片优化建议

1. **图片格式**：
   - 优先使用 WebP 格式（体积小）
   - PNG 用于需要透明背景的图标
   - JPG 用于照片类图片

2. **图片尺寸**：
   - TabBar 图标：81px × 81px
   - 商品图片：建议 300px × 300px 或更大（按需缩放）
   - 封面图片：建议 750px × 300px（适配小程序宽度）

3. **图片压缩**：
   - 使用工具压缩图片，减小体积
   - 推荐工具：TinyPNG、ImageOptim

## 如何添加图片

### 方法一：通过微信开发者工具

1. 在微信开发者工具中，右键点击 `images` 文件夹
2. 选择"新建文件"或直接拖拽图片文件
3. 将图片放入对应文件夹

### 方法二：通过文件管理器

1. 打开文件管理器，导航到 `D:\小程序\images\`
2. 将图片文件复制到对应文件夹
3. 在微信开发者工具中刷新项目

### 方法三：使用命令行

```bash
# 复制图片到对应文件夹
copy "图片路径" "D:\小程序\images\tabbar\home.png"
```

## 注意事项

1. **图片命名**：
   - 使用小写字母和连字符
   - 避免使用中文和特殊字符
   - 示例：`home.png`、`goods-default.png`

2. **图片路径**：
   - 小程序中引用图片使用相对路径
   - 示例：`/images/tabbar/home.png`
   - 注意：路径以 `/` 开头表示从项目根目录开始

3. **图片大小**（代码质量要求）：
   - **单张图片/音频不得超过 200KB**，否则「代码质量」中「图片和音频资源大小应不超过 200K」会不通过。
   - 建议用 [TinyPNG](https://tinypng.com/) 或开发者工具压缩；智能体图 `agent.png` 若超过 200K 请缩小尺寸或压缩后替换。
   - 总图片资源建议不超过 2MB（小程序包大小限制）。

4. **图片更新**：
   - 修改图片后，需要在微信开发者工具中重新编译
   - 如果图片没有更新，尝试清除缓存后重新编译
