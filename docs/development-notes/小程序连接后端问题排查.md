# 小程序无法连接后端问题排查

## 🔴 当前问题

后端服务器已启动，但小程序页面显示"没有启动"或"无法连接服务器"。

---

## ✅ 解决步骤

### 步骤1：检查 API 地址配置（最重要）

**文件**：`app.js`

**问题**：API 地址中可能有空格或配置错误

**检查**：
```javascript
globalData: {
  apiBaseUrl: 'http://192.168.200.120:8080/api'  // ✅ 正确（注意：http://后面不要有空格）
  // apiBaseUrl: 'http:// 192.168.200.120:8080/api'  // ❌ 错误（有空格）
}
```

**常见错误**：
- ❌ `'http:// 192.168.200.120:8080/api'` - http://后面有空格
- ❌ `'http://192.168.200.120:8080/api '` - 末尾有空格
- ❌ `'http://192.168.200.120:8080/api'` - 如果后端在本地，应该用 localhost

**修复**：
1. 打开 `app.js`
2. 找到 `apiBaseUrl` 配置
3. 确保没有多余空格
4. 保存文件
5. 在微信开发者工具中重新编译

---

### 步骤2：确认后端服务地址

**检查后端实际运行地址**：

1. **查看后端启动日志**
   - 在 IDE 控制台中查看
   - 应该看到：`Tomcat started on port(s): 8080 (http) with context path '/api'`

2. **确认服务器IP地址**
   - 如果后端运行在本地：使用 `http://localhost:8080/api`
   - 如果后端运行在其他机器：使用 `http://实际IP:8080/api`

3. **测试后端是否可访问**
   - 在浏览器中访问：`http://192.168.200.120:8080/api/user/login`
   - 应该返回 JSON 响应（即使是错误也说明服务已启动）

---

### 步骤3：检查微信开发者工具设置

**重要**：开发环境必须关闭域名校验！

**设置步骤**：
1. 在微信开发者工具中
2. 点击右上角 **"详情"**
3. 选择 **"本地设置"** 标签
4. 勾选以下选项：
   - ✅ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

**如果没有勾选**：
- 小程序无法访问本地或内网地址
- 会提示"不在合法域名列表中"

---

### 步骤4：检查网络连接

**如果后端在其他机器（192.168.200.120）**：

1. **确认网络连通**
   - 在命令行执行：`ping 192.168.200.120`
   - 应该能 ping 通

2. **确认端口开放**
   - 检查防火墙是否阻止了 8080 端口
   - 检查后端服务器防火墙设置

3. **确认后端服务监听地址**
   - 后端默认只监听 localhost（127.0.0.1）
   - 如果需要从其他机器访问，需要配置监听 0.0.0.0

**修改后端监听地址**（如果需要）：

**文件**：`backend/src/main/resources/application.yml`

```yaml
server:
  port: 8080
  address: 0.0.0.0  # 添加这一行，监听所有网络接口
  servlet:
    context-path: /api
```

---

### 步骤5：查看小程序控制台错误

**查看方法**：
1. 在微信开发者工具中
2. 点击底部 **"Console"** 标签
3. 查看红色错误信息

**常见错误信息**：

1. **"request:fail"**
   - 原因：无法连接到服务器
   - 解决：检查 API 地址、网络连接、防火墙

2. **"不在合法域名列表中"**
   - 原因：未关闭域名校验
   - 解决：关闭域名校验（见步骤3）

3. **"network timeout"**
   - 原因：请求超时
   - 解决：检查后端服务是否正常运行

---

## 🔍 快速排查清单

按顺序检查：

- [ ] **API 地址配置正确**（`app.js` 中 `apiBaseUrl` 没有空格）
- [ ] **后端服务已启动**（看到启动成功日志）
- [ ] **后端地址可访问**（浏览器能访问 `http://地址:8080/api/user/login`）
- [ ] **微信开发者工具已关闭域名校验**
- [ ] **网络连接正常**（如果后端在其他机器，能 ping 通）
- [ ] **端口未被占用**（8080 端口正常）
- [ ] **小程序已重新编译**（修改配置后需要重新编译）

## ⚠️ 常见问题

### 问题1：API 地址有空格

**错误**：
```javascript
apiBaseUrl: 'http:// 192.168.200.120:8080/api'  // 有空格
```

**正确**：
```javascript
apiBaseUrl: 'http://192.168.200.120:8080/api'  // 无空格
```

### 问题2：后端只监听 localhost

**现象**：本地可以访问，但其他机器无法访问

**解决**：在 `application.yml` 中添加：
```yaml
server:
  address: 0.0.0.0  # 监听所有网络接口
```

### 问题3：防火墙阻止

**Windows 防火墙**：
1. 打开"Windows Defender 防火墙"
2. 点击"高级设置"
3. 添加入站规则，允许 8080 端口

### 问题4：未关闭域名校验

**必须关闭**，否则小程序无法访问本地或内网地址。
