## 阶段二：数据库设计与基础功能 ✅ 已完成

- `PointsRecordMapper.java`
- `GoodsMapper.java`

### 3. 用户模块后端 ✅

已实现：
- `LoginRequest.java` - 登录请求DTO
- `UserVO.java` - 用户视图对象
- `LoginVO.java` - 登录响应VO
- `WechatUtil.java` - 微信工具类（调用微信接口）
- `UserService.java` - 用户服务类
  - login() - 用户登录
  - getUserInfo() - 获取用户信息
  - updateUserInfo() - 更新用户信息
  - getUserPoints() - 获取用户积分
- `UserController.java` - 用户控制器
  - POST /user/login - 微信登录
  - GET /user/info - 获取用户信息
  - PUT /user/update - 更新用户信息
  - GET /user/points - 获取用户积分
