# 小程序开发规范

> 本文档用于指导小程序开发，每次编程前请仔细阅读并遵循以下规范。

## 一、代码规范

### 1.1 命名规范
- **文件命名**：使用小写字母，多个单词用连字符（-）分隔
  - 示例：`user-profile.js`、`order-list.wxml`
- **变量命名**：使用驼峰命名法（camelCase）
  - 示例：`userName`、`orderList`、`isLoading`
- **常量命名**：使用全大写字母，单词间用下划线分隔
  - 示例：`API_BASE_URL`、`MAX_RETRY_COUNT`
- **函数命名**：使用驼峰命名法，动词开头
  - 示例：`getUserInfo()`、`handleSubmit()`、`formatDate()`
- **组件命名**：使用 PascalCase（大驼峰）
  - 示例：`UserCard`、`OrderItem`

### 1.2 代码结构
- **页面结构**：按照 `data` → `onLoad` → `onShow` → `onReady` → 生命周期函数 → 事件处理函数 → 自定义方法的顺序组织
- **组件结构**：按照 `properties` → `data` → `lifetimes` → `methods` 的顺序组织
- **函数顺序**：生命周期函数 → 事件处理函数 → 工具函数

### 1.3 注释规范
- 每个页面/组件顶部添加功能说明注释
- 复杂逻辑必须添加注释说明
- 公共方法必须添加 JSDoc 风格注释
- 示例：
```javascript
/**
 * 获取用户信息
 * @param {string} userId - 用户ID
 * @returns {Promise<Object>} 用户信息对象
 */
async getUserInfo(userId) {
  // 实现逻辑
}
```

## 二、小程序特定规范

### 2.1 页面配置
- 每个页面必须配置 `app.json` 中的页面路径
- 页面标题、导航栏样式统一在 `app.json` 或页面 `json` 文件中配置
- 使用合理的页面路径，避免过深嵌套

### 2.2 数据管理
- **页面数据**：使用 `data` 定义初始数据
- **全局数据**：使用 `getApp()` 获取全局数据，或使用状态管理库
- **数据更新**：统一使用 `this.setData()` 更新数据，避免直接修改
- **数据校验**：接口返回数据必须进行校验和容错处理

### 2.3 事件处理
- 事件命名：`on` + 事件类型 + 描述
  - 示例：`onTapSubmit`、`onInputChange`、`onScrollToLower`
- 事件处理函数统一放在 `methods` 中
- 避免在模板中写复杂逻辑，将逻辑提取到方法中

### 2.4 样式规范
- 使用 rpx 作为尺寸单位（响应式像素）
- 颜色值使用十六进制或 rgba
- 公共样式提取到 `app.wxss`
- 避免使用内联样式，统一使用 class

## 三、性能优化

### 3.1 页面性能
- 控制 `setData` 频率，避免频繁调用
- 合并 `setData` 操作，减少渲染次数
- 长列表使用虚拟列表或分页加载
- 图片使用合适的尺寸，启用懒加载

### 3.2 网络请求
- 统一封装网络请求方法
- 添加请求超时和重试机制
- 合理使用缓存，减少重复请求
- 使用 Promise 或 async/await 处理异步操作

### 3.3 资源优化
- 图片压缩，使用合适的格式（WebP 优先）
- 控制包体积，单个包不超过 2MB
- 使用分包加载，按需加载页面

## 四、错误处理

### 4.1 异常捕获
- 所有异步操作必须添加错误处理
- 使用 try-catch 捕获同步错误
- 网络请求必须处理失败情况
- 用户操作失败时给出友好提示

### 4.2 日志记录
- 关键操作记录日志
- 错误信息记录详细上下文
- 生产环境避免输出敏感信息

## 五、用户体验

### 5.1 加载状态
- 网络请求时显示加载提示
- 使用 `wx.showLoading()` 和 `wx.hideLoading()`
- 长操作提供进度反馈

### 5.2 错误提示
- 错误信息清晰易懂
- 使用 `wx.showToast()` 提示用户
- 提供重试或返回选项

### 5.3 交互反馈
- 按钮点击提供视觉反馈
- 表单验证实时提示
- 操作成功给予明确反馈

## 六、安全规范

### 6.1 数据安全
- 敏感信息不存储在本地
- 用户输入必须进行校验和过滤
- 接口参数进行加密处理（如需要）

### 6.2 权限管理
- 合理申请用户权限
- 权限申请前说明用途
- 权限被拒绝时提供替代方案

## 七、代码质量

### 7.1 代码复用
- 公共逻辑提取为工具函数
- 公共组件封装复用
- 避免重复代码

### 7.2 代码可读性
- 保持函数单一职责
- 函数长度控制在 50 行以内
- 使用有意义的变量名
- 保持适当的代码缩进和空行

### 7.3 版本控制
- 提交前检查代码格式
- 提交信息清晰描述变更内容
- 避免提交临时文件和调试代码

## 八、测试规范

### 8.1 功能测试
- 开发完成后进行功能自测
- 测试各种边界情况
- 测试异常场景

### 8.2 兼容性测试
- 测试不同机型
- 测试不同微信版本
- 测试不同网络环境

### 9.2 网络请求封装
```javascript
// 统一请求方法
request(url, method = 'GET', data = {}) {
  return new Promise((resolve, reject) => {
    wx.request({
      url: url,
      method: method,
      data: data,
      success: (res) => {
        if (res.statusCode === 200) {
          resolve(res.data)
        } else {
          reject(res)
        }
      },
      fail: (err) => {
        reject(err)
      }
    })
  })
}
```

```javascript
// utils/request.js
const BASE_URL = 'https://your-api-domain.com/api';
const TOKEN_KEY = 'token';

class Request {
  // 统一请求方法
  request(url, method = 'GET', data = {}) {
    return new Promise((resolve, reject) => {
      const token = wx.getStorageSync(TOKEN_KEY);
      
      wx.request({
        url: BASE_URL + url,
        method: method,
        data: data,
        header: {
          'Content-Type': 'application/json',
          'Authorization': token ? `Bearer ${token}` : ''
        },
        success: (res) => {
          if (res.statusCode === 200) {
            if (res.data.code === 200) {
              resolve(res.data.data);
            } else if (res.data.code === 401) {
              // Token过期，重新登录
              this.handleTokenExpired();
              reject(res.data);
            } else {
              wx.showToast({
                title: res.data.message || '请求失败',
                icon: 'none'
              });
              reject(res.data);
            }
          } else {
            reject(res);
          }
        },
        fail: (err) => {
          wx.showToast({
            title: '网络错误',
            icon: 'none'
          });
          reject(err);
        }
      });
    });
  }

  // Token过期处理
  handleTokenExpired() {
    wx.removeStorageSync(TOKEN_KEY);
    wx.reLaunch({
      url: '/pages/login/login'
    });
  }

  // GET请求
  get(url, data = {}) {
    return this.request(url, 'GET', data);
  }

  // POST请求
  post(url, data = {}) {
    return this.request(url, 'POST', data);
  }

  // PUT请求
  put(url, data = {}) {
    return this.request(url, 'PUT', data);
  }
}

export default new Request();
```

```java
// util/JwtUtil.java
@Component
public class JwtUtil {
    @Value("${jwt.secret}")
    private String secret;
    
    @Value("${jwt.expiration}")
    private Long expiration;

    // 生成Token
    public String generateToken(Long userId, String openid) {
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + expiration);

        return Jwts.builder()
                .setSubject(String.valueOf(userId))
                .claim("openid", openid)
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .signWith(SignatureAlgorithm.HS512, secret)
                .compact();
    }

    // 解析Token
    public Claims getClaimsFromToken(String token) {
        return Jwts.parser()
                .setSigningKey(secret)
                .parseClaimsJws(token)
                .getBody();
    }

    // 验证Token
    public boolean validateToken(String token) {
        try {
            Claims claims = getClaimsFromToken(token);
            return !claims.getExpiration().before(new Date());
        } catch (Exception e) {
            return false;
        }
    }
}
```

```java
// service/CheckinService.java
@Service
public class CheckinService {
    @Autowired
    private CheckinRecordMapper checkinRecordMapper;
    
    @Autowired
    private UserMapper userMapper;
    
    @Autowired
    private PointsService pointsService;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    // 提交打卡
    @Transactional
    public CheckinRecord submitCheckin(Long userId, Integer waterMl) {
        // 1. 保存打卡记录
        CheckinRecord record = new CheckinRecord();
        record.setUserId(userId);
        record.setWaterMl(waterMl);
        record.setCheckinTime(new Date());
        record.setCheckinDate(LocalDate.now());
        
        // 2. 计算积分（每100ml = 1积分，每日上限50积分）
        int points = Math.min(waterMl / 100, 50);
        record.setPointsEarned(points);
        
        checkinRecordMapper.insert(record);
        
        // 3. 增加用户积分
        if (points > 0) {
            pointsService.addPoints(userId, points, "CHECKIN", record.getId());
        }
        
        // 4. 更新Redis缓存
        String key = "checkin:today:" + userId + ":" + LocalDate.now();
        redisTemplate.opsForValue().set(key, record, 24, TimeUnit.HOURS);
        
        return record;
    }

    // 获取今日打卡数据
    public TodayCheckinVO getTodayCheckin(Long userId) {
        LocalDate today = LocalDate.now();
        
        // 从Redis获取
        String key = "checkin:today:" + userId + ":" + today;
        CheckinRecord cached = (CheckinRecord) redisTemplate.opsForValue().get(key);
        if (cached != null) {
            return convertToVO(cached);
        }
        
        // 从数据库查询
        List<CheckinRecord> records = checkinRecordMapper.selectList(
            new LambdaQueryWrapper<CheckinRecord>()
                .eq(CheckinRecord::getUserId, userId)
                .eq(CheckinRecord::getCheckinDate, today)
        );
        
        int totalWater = records.stream()
            .mapToInt(CheckinRecord::getWaterMl)
            .sum();
        
        User user = userMapper.selectById(userId);
        
        TodayCheckinVO vo = new TodayCheckinVO();
        vo.setCurrentWater(totalWater);
        vo.setTargetWater(user.getTargetWater());
        vo.setHistoryList(records);
        
        // 缓存结果
        redisTemplate.opsForValue().set(key, vo, 1, TimeUnit.HOURS);
        
        return vo;
    }
}
```

#### 11.6.5 积分兑换服务

```java
// service/ExchangeService.java
@Service
public class ExchangeService {
    @Autowired
    private GoodsMapper goodsMapper;
    
    @Autowired
    private ExchangeRecordMapper exchangeRecordMapper;
    
    @Autowired
    private UserMapper userMapper;
    
    @Autowired
    private PointsService pointsService;

    // 兑换商品
    @Transactional
    public ExchangeRecord exchangeGoods(Long userId, Long goodsId) {
        // 1. 查询商品
        Goods goods = goodsMapper.selectById(goodsId);
        if (goods == null || goods.getStatus() != 1) {
            throw new BusinessException("商品不存在或已下架");
        }
        
        if (goods.getStock() <= 0) {
            throw new BusinessException("商品库存不足");
        }
        
        // 2. 查询用户积分
        User user = userMapper.selectById(userId);
        if (user.getTotalPoints() < goods.getPointsRequired()) {
            throw new BusinessException("积分不足");
        }
        
        // 3. 扣减库存（使用乐观锁）
        int updateCount = goodsMapper.update(null,
            new LambdaUpdateWrapper<Goods>()
                .eq(Goods::getId, goodsId)
                .gt(Goods::getStock, 0)
                .setSql("stock = stock - 1")
        );
        
        if (updateCount == 0) {
            throw new BusinessException("库存不足，请重试");
        }
        
        // 4. 扣除积分
        pointsService.deductPoints(userId, goods.getPointsRequired(), 
            "EXCHANGE", goodsId);
        
        // 5. 创建兑换记录
        ExchangeRecord record = new ExchangeRecord();
        record.setUserId(userId);
        record.setGoodsId(goodsId);
        record.setGoodsName(goods.getName());
        record.setPointsUsed(goods.getPointsRequired());
        record.setStatus(0);
        exchangeRecordMapper.insert(record);
        
        return record;
    }
}
```

### 11.7 性能优化建议

#### 11.7.1 数据库优化

1. **索引优化**
   - 为常用查询字段建立索引（如 user_id + date 联合索引）
   - 避免过度索引，影响写入性能
   - 定期分析慢查询日志

2. **查询优化**
   - 使用分页查询，避免一次性加载大量数据
   - 使用批量查询替代循环查询
   - 合理使用 JOIN，避免 N+1 查询问题

3. **表结构优化**
   - 合理使用冗余字段（如兑换记录中的商品名称）
   - 大文本字段考虑单独存储
   - 历史数据定期归档

#### 11.7.2 Redis缓存策略

### 11.8 安全设计方案

#### 11.8.1 认证授权

1. **JWT Token 安全**
   ```java
   // Token配置
   jwt:
     secret: ${JWT_SECRET}  # 使用环境变量
     expiration: 7200000  # 2小时
   
   // Token刷新机制
   // 前端在Token即将过期时（剩余15分钟）自动刷新
   ```

2. **接口鉴权**
   ```java
   // 拦截器验证Token
   @Component
   public class AuthInterceptor implements HandlerInterceptor {
       @Autowired
       private JwtUtil jwtUtil;
       
       @Override
       public boolean preHandle(HttpServletRequest request, 
                               HttpServletResponse response, 
                               Object handler) {
           String token = request.getHeader("Authorization");
           if (token != null && token.startsWith("Bearer ")) {
               token = token.substring(7);
               if (jwtUtil.validateToken(token)) {
                   Claims claims = jwtUtil.getClaimsFromToken(token);
                   request.setAttribute("userId", Long.valueOf(claims.getSubject()));
                   return true;
               }
           }
           response.setStatus(401);
           return false;
       }
   }
   ```

   ```java
   // 使用 Redis 实现限流
   public boolean rateLimit(String key, int maxRequests, int windowSeconds) {
       String redisKey = "rate_limit:" + key;
       Long count = redisTemplate.opsForValue().increment(redisKey);
       if (count == 1) {
           redisTemplate.expire(redisKey, windowSeconds, TimeUnit.SECONDS);

   }
   ```
