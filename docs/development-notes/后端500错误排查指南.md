# 后端500错误排查指南

## 🔴 当前问题

后端返回500错误：
```json
{"code":500, "message":"系统异常,请稍后重试", "data": null, "timestamp":1771310615990}
```

**说明**：小程序已能连接到后端，但后端处理请求时出现服务器内部错误。

---

## ✅ 排查步骤（按优先级）

### 步骤1：查看后端控制台日志（最重要）

**在IDE控制台中查看详细错误信息**，这是最直接的排查方法。

**常见错误信息**：
- `Communications link failure` → 数据库连接失败
- `Connection refused` → Redis连接失败
- `Table 'water_app.user' doesn't exist` → 数据库表不存在
- `微信登录失败` → 微信配置错误
- `NullPointerException` → 空指针异常

**请把控制台的完整错误信息发给我！**

---

### 步骤2：检查数据库连接

**问题**：数据库连接失败或数据库不存在

**检查项**：

1. **MySQL服务是否启动**
   - 打开"服务"（services.msc）
   - 查找"MySQL"服务
   - 确保状态为"正在运行"

2. **数据库是否存在**
   - 打开MySQL客户端（如Navicat、MySQL Workbench）
   - 检查是否存在 `water_app` 数据库
   - 如果不存在，需要执行初始化脚本

3. **数据库配置是否正确**
   - 文件：`backend/src/main/resources/application.yml`
   - 检查：
     ```yaml
     spring:
       datasource:
         url: jdbc:mysql://localhost:3306/water_app?...
         username: root
         password: Cyy06115  # 确认密码正确
     ```

4. **执行数据库初始化脚本**
   - 文件：`backend/database/init.sql`
   - 在MySQL客户端中执行该脚本
   - 或使用命令行：
     ```bash
     mysql -u root -p < backend/database/init.sql
     ```

---

### 步骤3：检查Redis连接

**问题**：Redis服务未启动或连接失败

**检查项**：

1. **Redis服务是否启动**
   - Windows：打开"服务"，查找"Redis"服务
   - 或使用命令行：
     ```bash
     redis-cli ping
     ```
   - 应该返回 `PONG`

2. **Redis配置是否正确**
   - 文件：`backend/src/main/resources/application.yml`
   - 检查：
     ```yaml
     spring:
       redis:
         host: localhost
         port: 6379
         password:  # 如果有密码，填写密码
     ```

3. **临时解决方案**（如果Redis未安装）
   - 如果暂时不需要Redis，可以注释掉Redis相关代码
   - 但建议安装Redis（后续功能需要）

---

### 步骤4：检查微信配置

**问题**：微信AppID或Secret配置错误

**检查项**：

1. **微信配置是否正确**
   - 文件：`backend/src/main/resources/application.yml`
   - 检查：
     ```yaml
     wechat:
       appid: wxad5480ff983499bd  # 确认AppID正确
       secret: <YOUR_WECHAT_APPSECRET>  # 确认Secret正确
     ```

2. **验证微信配置**
   - 登录微信公众平台：https://mp.weixin.qq.com
   - 开发 → 开发管理 → 开发设置
   - 查看AppID和AppSecret是否匹配

3. **测试微信接口**
   - 如果AppID/Secret错误，登录时会失败
   - 查看后端日志中的错误信息

---

### 步骤5：检查数据库表是否存在

**问题**：数据库表未创建

**检查项**：

1. **检查表是否存在**
   - 在MySQL客户端中执行：
     ```sql
     USE water_app;
     SHOW TABLES;
     ```
   - 应该看到以下表：
     - `user`
     - `checkin_record`
     - `points_record`
     - `goods`
     - `exchange_record`
     - `chat_record`

2. **如果表不存在，执行初始化脚本**
   - 文件：`backend/database/init.sql`
   - 在MySQL客户端中执行

---

## 🛠️ 快速修复方案

### 方案1：数据库连接失败

**症状**：控制台显示 `Communications link failure` 或 `Connection refused`

**解决**：
1. 启动MySQL服务
2. 确认数据库 `water_app` 存在
3. 确认用户名密码正确
4. 执行 `backend/database/init.sql` 初始化数据库

---

### 方案2：Redis连接失败

**症状**：控制台显示 `Connection refused` 或 `Unable to connect to Redis`

**解决**：
1. 启动Redis服务
2. 或暂时注释掉Redis相关代码（不推荐，但可以临时解决）

**临时禁用Redis**（不推荐）：
在 `application.yml` 中注释掉Redis配置：
```yaml
# spring:
#   redis:
#     host: localhost
#     port: 6379
```

---

### 方案3：数据库表不存在

**症状**：控制台显示 `Table 'water_app.user' doesn't exist`

**解决**：
1. 执行数据库初始化脚本：
   ```bash
   mysql -u root -p water_app < backend/database/init.sql
   ```
2. 或在MySQL客户端中打开 `backend/database/init.sql` 并执行

---

### 方案4：微信配置错误

**症状**：控制台显示 `微信登录失败` 或 `errcode: 40013`

**解决**：
1. 检查 `application.yml` 中的微信配置
2. 登录微信公众平台确认AppID和Secret
3. 确保小程序已发布或使用测试号

---
