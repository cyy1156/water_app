# 粥粥喝水提醒 - 订阅消息模板配置说明

## 方案一：一次性订阅模拟长期提醒

每次发送提醒前，重新请求用户订阅授权。用户打开小程序时自动请求，或通过「立即请求提醒」按钮手动触发。

## 一、微信公众平台配置

### 1. 创建订阅消息模板

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入 **功能** → **订阅消息**
3. 点击 **公共模板库**，搜索「提醒」或自定义
4. 选择合适的模板，或使用以下建议字段：

**当前使用的模板结构**（模板ID: `KVB2gGSf6RhMW3xzaFAHDFkPReUEaF0eqYAxMlybve4`）：
- **thing1**：温馨提示（如：饮水时间到啦,请您记得适量饮水。）
- **thing5**：目标饮水量（如：1000ml）
- **time6**：饮水时间（格式：HH:mm，如：14:30）
- **phrase4**：距离上次饮水（如：2小时）

> 注意：
> - thing 类型字段最多 20 个字符，后端会自动截断
> - phrase 类型字段最多 5 个字符，后端会自动截断
> - time 类型字段格式为 HH:mm（24小时制）

### 2. 获取模板 ID

创建模板后，复制 **模板 ID**（形如 `KVB2gGSf6RhMW3xzaFAHDFk...`）。

### 3. 配置到后端

在 `backend/src/main/resources/application.yml` 中填写：

```yaml
wechat:
  subscribe:
    template-id:
      remind: '你的模板ID'
```

## 二、触发时机

### 1. 自动触发（用户打开首页）

- 条件：用户已开启「粥粥提醒」、已配置模板 ID
- 节流：同一用户 6 小时内最多请求一次
- 流程：请求订阅授权 → 用户同意 → 后端立即发送提醒消息

### 2. 手动触发（我的页）

- 点击「立即请求提醒」按钮
- 请求订阅授权 → 用户同意 → 后端立即发送提醒消息

## 三、消息内容

后端根据用户今日喝水进度自动生成：
- **thing1**：饮水时间到啦,请您记得适量饮水。
- **thing5**：目标饮水量（如：1000ml）
- **time6**：当前时间（格式：HH:mm，如：14:30）
- **phrase4**：距离上次饮水时间（如：刚刚、5分钟、2小时、1天、首次）

## 四、依赖说明

- **Redis**：用于缓存微信 `access_token`（2 小时有效期）
- **User.openid**：发送消息需要用户的 openid，登录时已保存

## 五、模板字段说明

当前模板使用以下字段：
- `thing1`：温馨提示（固定文案）
- `thing5`：目标饮水量（从用户设置读取）
- `time6`：当前时间（格式：HH:mm）
- `phrase4`：距离上次饮水（自动计算）

若需要使用其他模板，需修改：
1. `WechatSubscribeService.java` 中的 `sendRemindMessage` 方法参数和 `data` 的 key
2. `ReminderService.java` 中的 `sendRemindNow` 方法，生成对应的字段内容
