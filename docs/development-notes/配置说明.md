# 小程序配置说明

## 前端配置

### 1. API地址配置

在 `app.js` 中配置后端API地址：

```javascript
globalData: {
  userInfo: null,
  token: null,
  apiBaseUrl: 'http://localhost:8080/api'  // 本地开发环境
  // apiBaseUrl: 'https://your-domain.com/api'  // 生产环境
}
```

**注意**：
- 本地开发：使用 `http://localhost:8080/api` 或 `http://127.0.0.1:8080/api`
- 生产环境：使用实际的服务器地址
- 小程序要求生产环境必须使用 HTTPS

### 2. 微信小程序配置

在微信开发者工具中：
1. 设置 -> 项目设置 -> 本地设置
2. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"（仅开发环境）

## 后端配置

### 1. 数据库配置

在 `backend/src/main/resources/application.yml` 中配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/water_app?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: your_password  # 修改为你的数据库密码
```

### 2. Redis配置

```yaml
spring:
  redis:
    host: localhost
    port: 6379
    password:  # 如果有密码，填写密码
```

### 3. JWT配置

```yaml
jwt:
  secret: your-secret-key-change-in-production  # 修改为安全的密钥
  expiration: 7200000  # 2小时
```

### 4. 微信小程序配置

```yaml
wechat:
  appid: your-appid  # 你的小程序AppID
  secret: your-secret  # 你的小程序Secret
```

**获取AppID和Secret**：
1. 登录微信公众平台：https://mp.weixin.qq.com
2. 开发 -> 开发管理 -> 开发设置
3. 查看AppID和AppSecret

### 5. 初始化数据库

执行 `backend/database/init.sql` 脚本创建数据库和表。

## 启动步骤

### 后端启动

1. 确保MySQL和Redis服务已启动
2. 配置 `application.yml` 中的数据库、Redis、JWT、微信配置
3. 执行数据库初始化脚本
4. 启动SpringBoot应用

### 前端启动

1. 在微信开发者工具中打开项目
2. 配置 `app.js` 中的 `apiBaseUrl`
3. 编译运行

## 常见问题

### 1. 图片加载失败

已修复：使用条件渲染，没有图片时显示占位符。

### 2. 500错误

可能原因：
- 后端服务未启动
- API地址配置错误
- 数据库连接失败
- 微信配置错误

解决方法：
1. 检查后端服务是否启动
2. 检查API地址是否正确
3. 查看后端日志
4. 检查数据库和Redis连接

### 3. 401未授权错误

可能原因：
- Token过期
- Token无效

解决方法：
- 小程序会自动重新登录
- 检查JWT配置是否正确

### 4. 网络请求失败

可能原因：
- API地址配置错误
- 后端服务未启动
- 跨域问题

解决方法：
1. 检查API地址配置
2. 确保后端服务已启动
3. 开发环境可以关闭域名校验
