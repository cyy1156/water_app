# 生产环境域名配置说明

## 📌 重要说明

**生产环境域名不是固定的**，需要根据你的实际部署情况来确定。

---

## 🎯 如何确定你的生产环境域名？

### 情况1：已有服务器和域名

**如果你已经购买了域名并部署了服务器**：

**步骤**：
1. 确认你的域名（如：`example.com`）
2. 确认API服务的子域名（如：`api.example.com`）
3. 配置为：`https://api.example.com/api`

**示例**：
```javascript
// app.js
globalData: {
  apiBaseUrl: 'https://api.example.com/api'
}
```

---

### 情况2：使用云服务器（阿里云、腾讯云等）

#### 选项A：使用云服务商提供的临时域名

**阿里云/腾讯云**通常会提供一个临时域名，格式如：
- `your-app-name.oss-cn-hangzhou.aliyuncs.com`
- `your-app-name.ap-shanghai.app.tcloudbase.com`

**配置**：
```javascript
apiBaseUrl: 'https://your-app-name.oss-cn-hangzhou.aliyuncs.com/api'
```

#### 选项B：购买并绑定独立域名

**步骤**：
1. 购买域名（如：在阿里云、腾讯云购买）
2. 在域名解析中添加记录：
   - 类型：A 记录 或 CNAME
   - 主机记录：`api`（或 `www`）
   - 记录值：你的服务器IP地址
3. 配置SSL证书（必须，小程序要求HTTPS）
4. 配置为：`https://api.yourdomain.com/api`

---

### 情况3：使用云服务（Serverless）

#### 腾讯云开发（CloudBase）

**获取域名**：
1. 登录腾讯云开发控制台
2. 进入"云函数"或"云托管"
3. 查看提供的访问域名
4. 格式如：`your-app-id.ap-shanghai.app.tcloudbase.com`

**配置**：
```javascript
apiBaseUrl: 'https://your-app-id.ap-shanghai.app.tcloudbase.com/api'
```

#### 阿里云函数计算

**获取域名**：
1. 登录阿里云函数计算控制台
2. 查看函数详情
3. 获取访问域名

#### 微信云开发

**获取域名**：
1. 在微信开发者工具中开通云开发
2. 查看云函数域名
3. 配置为云函数地址

---

### 情况4：使用内网穿透（开发/测试）

**适用于**：后端部署在本地，需要外网访问

**工具**：
- **ngrok**：https://ngrok.com
- **natapp**：https://natapp.cn
- **花生壳**：https://hsk.oray.com
- **cpolar**：https://www.cpolar.com

**步骤**：
1. 注册并下载内网穿透工具
2. 配置本地端口（如：8080）
3. 获取穿透后的域名（如：`abc123.ngrok.io`）
4. 配置为：`https://abc123.ngrok.io/api`

**注意**：
- 免费版域名可能经常变化
- 仅适用于开发测试，不建议生产环境使用

---

### 情况5：使用Docker部署

**如果使用Docker部署**：

1. **使用服务器IP + 端口**（不推荐，不安全）
   ```javascript
   apiBaseUrl: 'http://123.456.789.0:8080/api'  // 仅开发测试
   ```

2. **绑定域名**（推荐）
   - 购买域名
   - 配置Nginx反向代理
   - 配置SSL证书
   - 使用域名访问

## 🔍 如何查找你的域名？

### 方法1：查看服务器配置

**如果你有服务器访问权限**：

```bash
# 查看Nginx配置
cat /etc/nginx/nginx.conf
# 或
cat /etc/nginx/sites-enabled/default

# 查看Apache配置
cat /etc/apache2/sites-enabled/000-default.conf
```

### 方法2：查看云服务控制台

**阿里云**：
1. 登录阿里云控制台
2. 进入"域名"或"云服务器ECS"
3. 查看已绑定的域名

**腾讯云**：
1. 登录腾讯云控制台
2. 进入"域名注册"或"云服务器CVM"
3. 查看已绑定的域名

### 方法3：查看DNS解析记录

**如果你知道域名**：
1. 访问：https://dnschecker.org
2. 输入你的域名
3. 查看解析到的IP地址

## ⚙️ 配置步骤

### 步骤1：确定域名

根据上述情况，确定你的生产环境域名。

### 步骤2：配置SSL证书（必须）

**小程序要求必须使用HTTPS**，所以需要配置SSL证书。

**获取SSL证书的方式**：

1. **免费证书**：
   - Let's Encrypt（免费，3个月有效期）
   - 阿里云SSL证书（免费版）
   - 腾讯云SSL证书（免费版）

2. **付费证书**：
   - 各大云服务商提供

**配置SSL证书**：
- 如果使用Nginx，配置在Nginx中
- 如果使用云服务，在控制台配置

### 步骤3：配置前端

**文件**：`app.js`

```javascript
globalData: {
  apiBaseUrl: 'https://你的域名/api'  // 替换为实际域名
}
```

### 步骤4：配置微信小程序服务器域名

**重要**：必须在微信公众平台配置服务器域名，否则小程序无法访问。

**配置步骤**：
1. 登录微信公众平台：https://mp.weixin.qq.com
2. 进入"开发" -> "开发管理" -> "开发设置"
3. 找到"服务器域名"配置
4. 配置以下域名：
   - **request 合法域名**：`https://你的域名`（不带/api）
   - **uploadFile 合法域名**：`https://你的域名`（如果使用OSS，填写OSS域名）
   - **downloadFile 合法域名**：`https://你的域名`

**注意事项**：
- 域名必须使用 HTTPS
- 域名必须已备案（国内服务器）
- 每月只能修改 5 次
- 修改后需要重新发布小程序才能生效

## 📋 配置检查清单

在配置生产环境域名前，确认：

- [ ] 已确定生产环境域名
- [ ] 域名已解析到服务器IP
- [ ] 已配置SSL证书（HTTPS）
- [ ] 后端服务已部署并运行
- [ ] 可以通过浏览器访问：`https://你的域名/api/user/login`
- [ ] `app.js` 中 `apiBaseUrl` 已配置
- [ ] 微信公众平台已配置服务器域名

## 🎯 常见域名格式示例

### 标准格式

```
https://api.yourdomain.com/api
```

**说明**：
- `https://` - 协议（必须）
- `api` - 子域名（可选，也可以是 `www` 或其他）
- `yourdomain.com` - 你的主域名
- `/api` - API路径（根据后端配置）

### 其他格式示例

```
https://yourdomain.com/api          # 使用主域名
https://www.yourdomain.com/api      # 使用www子域名
https://backend.yourdomain.com/api  # 使用backend子域名
https://api.yourdomain.com          # 如果后端context-path是/api，这里不需要再加/api
```

**推荐服务商**：

**价格**：通常每年几十到几百元

**步骤**：
1. 注册账号
2. 搜索并购买域名
3. 配置DNS解析
4. 配置SSL证书

### 方案2：使用云服务提供的域名

**腾讯云开发**、**阿里云函数计算**等云服务会提供默认域名，可以直接使用。

### 方案3：使用内网穿透（仅开发测试）

使用ngrok、natapp等工具获取临时域名，**仅用于开发测试**。

## 🔧 测试域名是否可用

### 方法1：浏览器测试

在浏览器中访问：
```
https://你的域名/api/user/login
```

**应该返回**：
- JSON格式的响应（即使是错误信息也说明域名可用）
- 如果显示"无法访问"或"连接超时"，说明域名配置有问题

### 方法2：使用curl命令

```bash
curl https://你的域名/api/user/login
```

### 方法3：在小程序中测试

1. 配置 `app.js` 中的 `apiBaseUrl`
2. 在小程序中触发登录
3. 查看控制台是否有网络错误

## ⚠️ 常见问题

### 问题1：域名无法访问

**可能原因**：
- DNS解析未生效（等待几分钟到几小时）
- 服务器未启动
- 防火墙阻止了端口
- SSL证书配置错误

**解决方法**：
1. 检查DNS解析是否正确
2. 检查服务器是否运行
3. 检查防火墙设置
4. 检查SSL证书配置

### 问题2：小程序提示"不在合法域名列表中"

**原因**：未在微信公众平台配置服务器域名

**解决方法**：
1. 登录微信公众平台
2. 配置服务器域名
3. 重新发布小程序

### 问题3：HTTPS证书错误

**原因**：SSL证书配置不正确或已过期

**解决方法**：
1. 检查证书是否有效
2. 重新配置SSL证书
3. 确保证书链完整

## 🎯 总结

**生产环境域名配置流程**：

1. **确定域名** → 根据部署方式选择
2. **配置SSL证书** → 必须使用HTTPS
3. **配置前端** → 修改 `app.js` 中的 `apiBaseUrl`
4. **配置微信平台** → 在微信公众平台添加服务器域名
5. **测试验证** → 确保可以正常访问

**记住**：
- ✅ 必须使用 HTTPS
- ✅ 必须在微信平台配置
- ✅ 域名必须已备案（国内）

---

**如果你还没有域名，建议**：
1. 开发阶段：使用内网穿透工具（ngrok等）
2. 测试阶段：使用云服务提供的临时域名
3. 生产环境：购买独立域名并配置SSL证书
