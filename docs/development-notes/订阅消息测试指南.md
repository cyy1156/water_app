# 粥粥喝水提醒 - 测试指南

## 一、前置检查

### 1. 配置检查

**检查 `application.yml` 配置：**
```yaml
wechat:
  appid: wxad5480ff983499bd
  secret: <YOUR_WECHAT_APPSECRET>
  subscribe:
    template-id:
      remind: 'KVB2gGSf6RhMW3xzaFAHDFkPReUEaF0eqYAxMlybve4'  # 必须填写
```

**检查 Redis 是否启动：**
```bash
# Windows PowerShell
redis-cli ping
# 应该返回: PONG
```

### 2. 数据库检查

确保已执行数据库迁移：
```bash
# 运行迁移脚本
cd backend/database
run_migrate_m4.bat
```

检查表是否存在：
```sql
USE water_app;
SHOW TABLES LIKE 'user_reminder_setting';
```

## 二、测试步骤

### 方法一：小程序端测试（推荐）

#### 步骤 1：开启提醒设置

1. 打开小程序，进入 **我的** 页面
2. 找到 **粥粥提醒** 区域
3. 打开 **开启粥粥提醒** 开关
4. 此时会弹出微信订阅消息授权弹窗
5. 点击 **允许** 授权订阅

**预期结果：**
- 开关保持开启状态
- 显示提示："已开启粥粥提醒～"

#### 步骤 2：手动触发提醒（我的页）

1. 在 **我的** 页面，点击 **立即请求提醒** 按钮
2. 再次弹出订阅授权弹窗
3. 点击 **允许**
4. 查看微信消息列表

**预期结果：**
- 显示提示："粥粥提醒已发送～"
- 微信收到订阅消息，包含：
  - 温馨提示：饮水时间到啦,请您记得适量饮水。
  - 目标饮水量：如 2000ml
  - 饮水时间：如 14:30
  - 距离上次饮水：如 2小时

#### 步骤 3：自动触发提醒（首页）

1. 确保已开启提醒设置
2. 关闭小程序（完全退出）
3. 等待 6 小时以上（或修改代码中的节流时间）
4. 重新打开小程序，进入首页
5. 查看微信消息列表

**预期结果：**
- 自动弹出订阅授权弹窗
- 授权后收到提醒消息

## 三、调试方法

### 1. 查看后端日志

**检查 access_token 获取：**
```
[INFO] 从 Redis 读取 access_token 成功
或
[INFO] 获取 access_token 成功，已缓存到 Redis
```

**检查消息发送：**
```
[INFO] 订阅消息发送成功
或
[ERROR] 订阅消息发送失败 errcode=40001 errmsg=invalid credential
```

**检查提醒发送：**
```
[INFO] 喝水提醒已发送 userId=1, thing1=..., thing5=..., time6=..., phrase4=...
```

### 2. 检查 Redis 缓存

```bash
redis-cli
> GET wechat:access_token
# 应该返回一个 token 字符串（2小时内有效）
```

### 3. 前端调试

**打开小程序调试：**
1. 微信开发者工具 → **调试器** → **Console**
2. 查看是否有错误信息

**检查存储：**
```javascript
// 在开发者工具 Console 中执行
wx.getStorageSync('lastSubscribeRequestTime')
// 应该返回一个时间戳（毫秒）
```

### 4. 常见问题排查

#### 问题 1：授权弹窗不出现

**可能原因：**
- 模板 ID 未配置或为空
- 用户已拒绝过订阅（需等待 7 天或清除授权）

**解决方法：**
- 检查 `application.yml` 中的 `wechat.subscribe.template-id.remind`
- 在微信开发者工具中清除授权：**设置** → **清除授权数据**

#### 问题 2：消息发送失败

**可能原因：**
- access_token 获取失败（检查 appid/secret）
- Redis 未启动
- 用户未授权订阅

**解决方法：**
- 检查后端日志中的错误信息
- 确认 Redis 服务运行正常
- 在小程序端重新授权订阅

#### 问题 3：消息内容不正确

**检查点：**
- 模板字段是否匹配（thing1, thing5, time6, phrase4）
- 字段长度是否超限（thing 20字，phrase 5字）
- 时间格式是否正确（HH:mm）

#### 问题 4：自动提醒不触发

**可能原因：**
- 6 小时节流限制（距离上次请求不足 6 小时）
- 提醒设置未开启

**解决方法：**
- 修改 `home.js` 中的 `SUBSCRIBE_INTERVAL_MS` 为更短时间（测试用）
- 或手动清除存储：`wx.removeStorageSync('lastSubscribeRequestTime')`

## 四、快速测试脚本

### 修改节流时间（测试用）

在 `pages/home/home.js` 中临时修改：

```javascript
// 测试用：改为 1 分钟
const SUBSCRIBE_INTERVAL_MS = 1 * 60 * 1000; // 1 分钟
```

### 清除节流限制（测试用）

在微信开发者工具 Console 中执行：

```javascript
wx.removeStorageSync('lastSubscribeRequestTime')
```

然后重新打开小程序首页，应该会立即触发订阅请求。

## 六、预期效果

**成功时：**
1. 用户授权订阅后，立即收到一条微信订阅消息
2. 消息包含：温馨提示、目标饮水量、当前时间、距离上次饮水时间
3. 点击消息可跳转到小程序首页
4. 后端日志显示发送成功

**失败时：**
- 查看后端日志中的错误信息
- 检查微信公众平台中的模板配置
- 确认用户是否已授权订阅
