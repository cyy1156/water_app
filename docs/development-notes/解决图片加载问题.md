# 解决图片加载超时问题

## 🔍 问题原因

`ERR_CONNECTION_TIMED_OUT` 表示无法连接到 `imgur.com`，这是因为：
- imgur.com 在中国可能被墙或访问不稳定
- 小程序需要配置合法域名才能访问外部图片

---

## ✅ 解决方案（推荐按顺序尝试）

### 方案一：使用国内可访问的图床（推荐）

#### 选项1：使用 sm.ms（免费，国内可访问）

1. **访问**：https://sm.ms
2. **上传图片**，复制图片URL
3. **更新数据库**：

```sql
USE `water_app`;

UPDATE `goods` SET `image_url` = 'https://s2.loli.net/2024/01/01/xxxxx.jpg' WHERE `name` = '精美水杯';
UPDATE `goods` SET `image_url` = 'https://s2.loli.net/2024/01/01/yyyyy.jpg' WHERE `name` = '健康手册';
```

#### 选项2：使用 placeholder.com（占位图片，快速测试）

> 说明：如果你的网络环境无法解析 `via.placeholder.com`（你当前就遇到了 `ERR_NAME_NOT_RESOLVED`），请直接跳到“方案二：使用本地图片”。

```sql
USE `water_app`;

-- 使用占位图片服务（300x300像素，显示商品名称）
UPDATE `goods` SET `image_url` = 'https://via.placeholder.com/300x300?text=精美水杯' WHERE `name` = '精美水杯';
UPDATE `goods` SET `image_url` = 'https://via.placeholder.com/300x300?text=健康手册' WHERE `name` = '健康手册';
UPDATE `goods` SET `image_url` = 'https://via.placeholder.com/300x300?text=定制T恤' WHERE `name` = '定制T恤';
UPDATE `goods` SET `image_url` = 'https://via.placeholder.com/300x300?text=运动手环' WHERE `name` = '运动手环';
UPDATE `goods` SET `image_url` = 'https://via.placeholder.com/300x300?text=水杯套装' WHERE `name` = '水杯套装';
UPDATE `goods` SET `image_url` = 'https://via.placeholder.com/300x300?text=健康秤' WHERE `name` = '健康秤';
```

#### 选项3：使用其他国内图床

- **七牛云**：https://www.qiniu.com（需要注册）
- **又拍云**：https://www.upyun.com（需要注册）
- **GitHub**：使用 GitHub 仓库存储图片（免费）

---

### 方案二：使用本地图片（通过后端服务）

如果图片存储在本地，需要：

1. **将图片放到** `backend/uploads/goods/` 目录
2. **更新数据库**，使用相对路径：

```sql
USE `water_app`;

-- 按你当前目录实际文件名填写（你本机目前是 png）
UPDATE `goods` SET `image_url` = '/uploads/goods/24efd398deea485189336bf09c24ccba.jpeg~tplv-a9rns2rl98-downsize_watermark_1_5_b.png' WHERE `name` = '精美水杯';
UPDATE `goods` SET `image_url` = '/uploads/goods/book.png' WHERE `name` = '健康手册';
-- ... 其他商品
```

3. **确保后端已配置静态资源映射**（已在 `WebMvcConfig.java` 中配置）

**注意**：前端代码会自动将 `/uploads/...` 路径拼接为完整URL。
你的后端配置了 `context-path: /api`，所以最终访问形如：`http://192.168.200.120:8080/api/uploads/goods/set.png`

---

### 方案三：配置小程序合法域名（如果必须使用 imgur）

如果必须使用 imgur，需要：

1. **登录微信公众平台**：https://mp.weixin.qq.com
2. **进入**："开发" -> "开发管理" -> "开发设置"
3. **配置 downloadFile 合法域名**：添加 `https://i.imgur.com`
4. **重新发布小程序**

**注意**：即使配置了域名，如果 imgur 无法访问，仍然会失败。

## 📝 后续建议

1. **开发阶段**：使用 placeholder.com 占位图片
2. **测试阶段**：上传真实图片到 sm.ms 或其他国内图床
3. **生产环境**：使用云存储（OSS/COS）或自己的服务器

---

## 🔧 如果仍然无法加载

检查以下几点：

1. ✅ **网络连接**：确保能访问互联网
2. ✅ **小程序合法域名**：如果使用外部图片，需要在微信平台配置
3. ✅ **图片URL格式**：确保是完整的 `https://...` 格式
4. ✅ **后端服务**：如果使用本地图片，确保后端服务运行正常

---

## 💡 推荐方案总结

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| placeholder.com | 快速、免费、稳定 | 只是占位图 | 开发测试 |
| sm.ms | 免费、国内可访问 | 需要上传图片 | 测试环境 |
| 本地图片 | 完全控制、稳定 | 需要存储空间 | 生产环境 |
| 云存储OSS | 专业、CDN加速 | 需要付费 | 生产环境 |

**建议**：先用 placeholder.com 快速测试，确认功能正常后，再上传真实图片到 sm.ms 或使用本地图片。
