# 商城与成就需求文档

## 一、概述

将「粥粥喝水」小程序的商城从「兑换实物」改为「兑换自我奖励」，并结合成就系统与提醒功能，形成「打卡 → 攒金币 → 兑换自我奖励 → 提醒执行 → 成就记录」的闭环。

---

## 二、商城改造（自我奖励兑换）

### 2.1 定位

- **原定位**：用金币兑换实物（水杯、T恤、手环等）。
- **新定位**：用金币兑换**对自己的奖励**，激励坚持喝水打卡。

### 2.2 商品类型示例

| 示例 | 描述 | 价格参考 |
|------|------|----------|
| 奖励自己喝一杯奶茶 | 达成目标后奖励自己喝一杯奶茶 | 金币 |
| 奖励自己买一件衣服 | 达成目标后奖励自己买一件心仪的衣服 | 金币 |
| 奖励自己看一场电影 | 达成目标后奖励自己看一场电影 | 金币 |
| 奖励自己清空购物车第一件商品 | 达成目标后奖励自己清空购物车第一件 | 金币 |

- 商品以「自我奖励」为主，可预设示例，也可支持用户自定义。
- 商品图片由运营后续替换。

### 2.3 兑换流程

1. 用户选择某个自我奖励商品，使用金币兑换。
2. 兑换成功后：
   - **自动加入提醒**：在提醒系统中创建对应提醒，用户可设定执行时间。
   - **自动加入成就**：在成就系统的「已兑换的奖励」专栏中展示。

---

## 三、成就系统

### 3.1 整体结构

成就页面包含**两个专栏**：

- **专栏一：我们设定的目标**（系统成就）
- **专栏二：自己兑换的东西**（用户兑换的自我奖励）

### 3.2 专栏一：我们设定的目标

- **含义**：系统预设的打卡目标成就。
- **规则示例**：
  - 连续 3 天打卡喝水 → 专属徽章 + 金币奖励
  - 连续 5 天打卡喝水 → 专属徽章 + 金币奖励
  - 连续 10 天打卡喝水 → 专属徽章 + 金币奖励
  - 可按需求扩展：连续 7、14、21、30 天等。
- **展示**：已达成时展示专属徽章、对应金币及达成时间。

### 3.3 专栏二：自己兑换的东西

- **含义**：用户使用金币兑换的自我奖励记录。
- **规则**：
  - 兑换成功后自动加入此专栏。
  - 展示兑换内容（如「喝一杯奶茶」「买一件衣服」等）、兑换时间。
  - 可与提醒关联，展示是否已执行。

---

## 四、提醒联动

- 用户兑换自我奖励后，系统自动生成一条提醒。
- 用户可设置提醒时间（如「本周六下午」）。
- 提醒发送方式沿用现有提醒能力（如订阅消息等）。

---

## 五、数据与流程

### 5.1 核心流程

```
打卡喝水 → 获得金币 → 商城兑换自我奖励 → 加入提醒 + 加入成就
                                    ↓
                            用户设定执行时间
                                    ↓
                            收到提醒，执行奖励
```

### 5.2 数据需求（概要）

- **商城商品表**：类型从「实物」调整为「自我奖励」，字段包括：名称、描述、所需金币、示例图片等。
- **成就表**：
  - 系统成就：连续 N 天打卡、徽章、金币。
  - 兑换成就：兑换内容、兑换时间、关联提醒 ID。
- **提醒表**：与兑换记录关联，存储提醒时间、内容等。

---

## 六、UI/UX 建议

1. **商城列表**：沿用现有列表布局，将商品改为自我奖励类，图片后续替换。
2. **成就页**：两个专栏上下或左右分区，可考虑 Tab 或分区标题区分。
3. **兑换弹窗**：确认兑换后，可引导用户设置提醒时间。
4. **徽章**：系统成就使用专属徽章图标，可预留多种样式（如铜/银/金）。
