# 验证小程序登录功能

## ✅ 后端状态

从日志可以看到：
- ✅ 后端服务已成功启动
- ✅ Tomcat 运行在 8080 端口
- ✅ 上下文路径：`/api`
- ⚠️ GET 请求错误（这是浏览器测试导致的，可以忽略）

---

## 🎯 验证步骤

### 步骤1：在微信开发者工具中运行小程序

1. **打开微信开发者工具**
2. **加载项目**：选择 `D:\小程序` 目录
3. **点击"编译"按钮**
4. **查看模拟器**，小程序应该正常显示

---

### 步骤2：查看小程序控制台

1. **点击底部"Console"标签**
2. **查看日志输出**，应该看到：
   ```
   小程序启动
   登录成功
   ```

3. **如果有错误**，会显示红色错误信息

---

### 步骤3：查看网络请求

1. **点击底部"Network"或"网络"标签**
2. **刷新小程序**（点击编译按钮）
3. **查找 `/user/login` 请求**
4. **确认请求方法**：
   - ✅ 应该是 **POST**
   - ❌ 不应该是 GET

5. **查看请求详情**：
   - **URL**：`http://192.168.200.120:8080/api/user/login`
   - **Method**：`POST`
   - **Request Payload**：`{"code":"xxx"}`

6. **查看响应**：
   - **Status**：`200`
   - **Response**：包含 `token` 和 `userInfo`

---

### 步骤4：验证登录成功

**如果登录成功，应该：**
- ✅ 控制台显示"登录成功"
- ✅ 网络请求返回 200 状态码
- ✅ 响应中包含 `token` 和 `userInfo`
- ✅ 小程序页面正常显示

**如果登录失败，可能的原因：**
- ❌ API 地址配置错误
- ❌ 微信 AppID/Secret 配置错误
- ❌ 数据库连接失败
- ❌ Redis 连接失败（如果已安装）

---

## 🔍 常见问题排查

### 问题1：控制台显示"登录失败"

**检查项**：
1. **API 地址是否正确**
   - 文件：`app.js`
   - 配置：`apiBaseUrl: 'http://192.168.200.120:8080/api'`
   - 确认没有空格

2. **后端服务是否运行**
   - 查看后端控制台，确认服务已启动

3. **网络连接是否正常**
   - 确认能访问后端地址

---

### 问题2：网络请求返回 500 错误

**可能原因**：
1. **数据库连接失败**
   - 检查 MySQL 服务是否启动
   - 检查数据库 `water_app` 是否存在
   - 执行 `backend/database/init.sql` 初始化数据库

2. **Redis 连接失败**（如果已安装）
   - 检查 Redis 服务是否启动

3. **微信配置错误**
   - 检查 `application.yml` 中的微信配置
   - 确认 AppID 和 Secret 正确

**解决方法**：
- 查看后端控制台的详细错误信息
- 根据错误信息解决问题

---

### 问题3：网络请求返回 401 错误

**原因**：Token 过期或无效

**解决方法**：
- 小程序会自动重新登录
- 如果持续失败，检查 JWT 配置

---

### 问题4：网络请求失败（无法连接）

**可能原因**：
1. **API 地址配置错误**
   - 检查 `app.js` 中的 `apiBaseUrl`
   - 确认没有多余空格

2. **后端服务未启动**
   - 确认后端服务正在运行

3. **网络连接问题**
   - 如果后端在其他机器，确认网络连通

4. **域名校验未关闭**
   - 微信开发者工具 → 详情 → 本地设置
   - 勾选"不校验合法域名..."

---
