#### 我的页（profile）
- ✅ 新增「粥粥提醒」区块

- ✅ 授权结果提交后端 `/ai/reminder/subscribe`
- ✅ 提醒设置保存到 `/ai/reminder/settings`
- ✅ 页面加载时获取提醒状态

#### 常量
- ✅ `AI_REMINDER_SETTINGS`、`AI_REMINDER_SUBSCRIBE`、`AI_REMINDER_TEMPLATE_ID`

### 4. 订阅消息流程 ✅

1. 用户在「我的」页打开「开启粥粥提醒」开关
2. 前端请求 `GET /ai/reminder/template-id`
3. 若模板 ID 已配置：调用 `wx.requestSubscribeMessage({ tmplIds: [templateId] })`
4. 用户授权/拒绝后，调用 `POST /ai/reminder/subscribe` 上报结果
5. 调用 `POST /ai/reminder/settings` 保存设置

**说明**：模板 ID 未配置时，仅保存开关状态，不弹订阅授权。需在微信公众平台创建模板后，在 `application.yml` 中配置 `wechat.subscribe.template-id.remind`。

## 🎯 使用说明

### 1. 执行数据库迁移
```bash
# 运行 backend/database/run_migrate_m4.bat
# 或在 MySQL 中执行 migrate_m4_reminder.sql
```

### 2. 配置订阅模板（可选）
1. 登录微信公众平台 → 功能 → 订阅消息
2. 创建「喝水提醒」模板，获取 templateId
3. 在 `application.yml` 中配置：
   ```yaml
   wechat:
     subscribe:
       template-id:
         remind: '你的模板ID'
   ```

### 3. 测试
- 打开「我的」页，切换「开启粥粥提醒」开关
- 若未配置模板 ID：开关可正常保存，不弹授权
- 若已配置：会弹出微信订阅授权，授权后保存
