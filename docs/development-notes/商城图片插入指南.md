# 商城图片插入指南

本指南提供三种插入商城商品图片的方法，你可以根据实际情况选择。

---

## 📋 方法一：使用网络图片URL（推荐，最简单）

**适用场景**：开发测试、快速上线

**优点**：
- ✅ 最简单，无需配置
- ✅ 不需要存储空间
- ✅ 图片加载速度快（使用CDN）

**步骤**：

### 1. 准备图片URL

你可以使用以下方式获取图片URL：
- **免费图床**：如 [imgur.com](https://imgur.com)、[sm.ms](https://sm.ms)
- **在线图片**：直接使用网络上的图片链接（注意版权）
- **云存储**：阿里云OSS、腾讯云COS等（生产环境推荐）

### 2. 更新数据库

打开 MySQL 客户端（如 Navicat、MySQL Workbench），执行以下 SQL：

```sql
USE `water_app`;

-- 更新单个商品的图片URL
UPDATE `goods` SET `image_url` = 'https://example.com/images/cup.jpg' WHERE `id` = 1;

-- 批量更新多个商品图片
UPDATE `goods` SET `image_url` = 'hhttps://i.imgur.com/Fj7ze2Y.png' WHERE `name` = '精美水杯';
UPDATE `goods` SET `image_url` = 'https://i.imgur.com/KsqcfQp.png' WHERE `name` = '健康手册';
UPDATE `goods` SET `image_url` = 'https://example.com/images/tshirt.jpg' WHERE `name` = '定制T恤';
UPDATE `goods` SET `image_url` = 'https://example.com/images/band.jpg' WHERE `name` = '运动手环';
UPDATE `goods` SET `image_url` = 'https://example.com/images/set.jpg' WHERE `name` = '水杯套装';
UPDATE `goods` SET `image_url` = 'https://example.com/images/scale.jpg' WHERE `name` = '健康秤';
```

### 3. 验证

在小程序中打开商城页面，查看商品图片是否正常显示。

## 📋 方法二：使用本地图片（开发环境）

**适用场景**：本地开发、测试

**优点**：
- ✅ 图片存储在本地，不依赖网络
- ✅ 可以完全控制图片

**步骤**：

### 1. 创建商品图片目录

在项目根目录创建图片存储目录：

```bash
# Windows
mkdir backend\uploads\goods

# Linux/Mac
mkdir -p backend/uploads/goods
```

### 2. 放置图片文件

将商品图片放入 `backend/uploads/goods/` 目录，例如：
```
backend/uploads/goods/
├── 24efd398deea485189336bf09c24ccba.jpeg~tplv-a9rns2rl98-downsize_watermark_1_5_b.png   # 精美水杯（你当前目录里已存在）
├── book.png                                                                              # 健康手册（你当前目录里已存在）
├── Tshirt.png                                                                            # 定制T恤（你当前目录里已存在，建议后续改为小写 tshirt.png 便于 Linux 部署）
├── watch.png                                                                             # 运动手环（你当前目录里已存在）
├── set.png                                                                               # 水杯套装（你当前目录里已存在）
└── scale.png                                                                             # 健康秤（你当前目录里已存在）
```

### 3. 配置静态资源映射

打开 `backend/src/main/java/com/waterapp/config/WebMvcConfig.java`，添加商品图片的静态资源映射：

```java
@Value("${app.chat.upload-dir:uploads/chat}")
private String chatUploadDir;

@Value("${app.goods.upload-dir:uploads/goods}")
private String goodsUploadDir;

@Override
public void addResourceHandlers(ResourceHandlerRegistry registry) {
    // 聊天图片访问路径
    String chatUploadPath = Paths.get(chatUploadDir).toAbsolutePath().toString();
    registry.addResourceHandler("/uploads/chat/**")
            .addResourceLocations("file:" + chatUploadPath + "/");
    
    // 商品图片访问路径（新增）
    String goodsUploadPath = Paths.get(goodsUploadDir).toAbsolutePath().toString();
    registry.addResourceHandler("/uploads/goods/**")
            .addResourceLocations("file:" + goodsUploadPath + "/");
}
```

### 4. 添加配置项

打开 `backend/src/main/resources/application.yml`，添加商品图片配置：

```yaml
app:
  chat:
    upload-dir: uploads/chat
  goods:
    upload-dir: uploads/goods  # 新增商品图片目录配置
```

### 5. 更新数据库

执行 SQL 更新图片URL：

```sql
USE `water_app`;

-- 使用本地路径（需要根据你的实际后端地址修改）
-- 假设后端运行在 http://localhost:8080/api
UPDATE `goods` SET `image_url` = '/uploads/goods/24efd398deea485189336bf09c24ccba.jpeg~tplv-a9rns2rl98-downsize_watermark_1_5_b.png' WHERE `name` = '精美水杯';
UPDATE `goods` SET `image_url` = '/uploads/goods/book.png' WHERE `name` = '健康手册';
UPDATE `goods` SET `image_url` = '/uploads/goods/Tshirt.png' WHERE `name` = '定制T恤';
UPDATE `goods` SET `image_url` = '/uploads/goods/watch.png' WHERE `name` = '运动手环';
UPDATE `goods` SET `image_url` = '/uploads/goods/set.png' WHERE `name` = '水杯套装';
UPDATE `goods` SET `image_url` = '/uploads/goods/scale.png' WHERE `name` = '健康秤';
```

**注意**：你的后端配置了 `context-path: /api`，因此浏览器直接访问图片应该是：

- `http://192.168.200.120:8080/api/uploads/goods/set.png`

小程序端会用 `apiBaseUrl`（例如 `http://192.168.200.120:8080/api`）自动拼接 `/uploads/...`，无需你手动去掉 `/api`。

```javascript
// 在小程序代码中，图片URL会拼接完整地址（apiBaseUrl 含 /api）
const imageUrl = getApp().globalData.apiBaseUrl + item.imageUrl;
```

## 📋 方法三：创建商品图片上传接口（最完善）

**适用场景**：生产环境、需要管理后台

**优点**：
- ✅ 可以通过接口上传图片
- ✅ 支持图片管理
- ✅ 可以添加图片压缩、格式转换等功能

### 1. 创建商品图片上传服务

创建 `backend/src/main/java/com/waterapp/service/GoodsImageService.java`：

```java
package com.waterapp.service;

import com.waterapp.common.exception.BusinessException;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.UUID;

@Slf4j
@Service
public class GoodsImageService {

    @Value("${app.goods.upload-dir:uploads/goods}")
    private String uploadDir;

    /**
     * 上传商品图片
     */
    public String uploadImage(MultipartFile file) {
        if (file == null || file.isEmpty()) {
            throw new BusinessException("上传文件不能为空");
        }

        // 验证文件类型
        String originalFilename = file.getOriginalFilename();
        String ext = "";
        if (originalFilename != null && originalFilename.contains(".")) {
            ext = originalFilename.substring(originalFilename.lastIndexOf("."));
        }
        
        if (!ext.matches("(?i)\\.(jpg|jpeg|png|gif|webp)")) {
            throw new BusinessException("只支持 jpg、jpeg、png、gif、webp 格式的图片");
        }

        // 生成文件名
        String filename = "goods_" + UUID.randomUUID().toString() + ext;

        try {
            // 创建目录
            Path dir = Paths.get(uploadDir).toAbsolutePath();
            Files.createDirectories(dir);

            // 保存文件
            Path target = dir.resolve(filename);
            file.transferTo(target.toFile());

            // 返回访问路径
            return "/uploads/goods/" + filename;
        } catch (IOException e) {
            log.error("保存商品图片失败", e);
            throw new BusinessException("图片上传失败，请稍后重试");
        }
    }
}
```

### 2. 创建上传接口

在 `MallController` 中添加图片上传接口：

```java
@PostMapping("/goods/upload")
public Result<Map<String, String>> uploadImage(HttpServletRequest request,
                                                @RequestParam("file") MultipartFile file) {
    try {
        String url = goodsImageService.uploadImage(file);
        Map<String, String> result = new HashMap<>();
        result.put("url", url);
        return Result.success(result);
    } catch (Exception e) {
        log.error("上传商品图片失败", e);
        return Result.error("上传图片失败：" + e.getMessage());
    }
}
```

### 3. 使用接口上传图片

**使用 Postman 测试**：
1. 选择 POST 方法
2. URL: `http://localhost:8080/api/mall/goods/upload`
3. Headers: `Authorization: Bearer {你的token}`
4. Body: 选择 `form-data`，添加 `file` 字段，选择图片文件
5. 发送请求，获取返回的 `url`

**使用小程序上传**：
```javascript
// 选择图片
wx.chooseImage({
  count: 1,
  success: (res) => {
    const tempFilePath = res.tempFilePaths[0];
    
    // 上传图片
    wx.uploadFile({
      url: getApp().globalData.apiBaseUrl + '/mall/goods/upload',
      filePath: tempFilePath,
      name: 'file',
      header: {
        'Authorization': 'Bearer ' + wx.getStorageSync('token')
      },
      success: (res) => {
        const data = JSON.parse(res.data);
        if (data.code === 200) {
          const imageUrl = data.data.url;
          // 使用 imageUrl 更新商品
          console.log('图片URL:', imageUrl);
        }
      }
    });
  }
});
```

## 📝 快速开始示例

```sql
USE `water_app`;

```

USE `water_app`;

-- 使用 placeholder.com 占位图片（300x300像素）

## ⚠️ 注意事项

1. **图片格式**：建议使用 `jpg`、`png`、`webp` 格式
2. **图片大小**：建议单张图片不超过 500KB，提高加载速度
3. **图片尺寸**：建议使用 300x300 或 400x400 像素的正方形图片
4. **URL 格式**：
   - 网络图片：使用完整的 `https://` URL
   - 本地图片：使用 `/uploads/goods/xxx.jpg` 格式
5. **跨域问题**：如果使用网络图片，确保图片服务器支持跨域访问

## 🔍 验证图片是否生效

执行以下 SQL 查询，检查图片URL是否正确：

```sql
USE `water_app`;

SELECT `id`, `name`, `image_url` FROM `goods` WHERE `status` = 1;
```

如果 `image_url` 字段有值，说明配置成功。在小程序中打开商城页面，应该能看到商品图片。

---

## 📞 遇到问题？

如果图片无法显示，检查以下几点：
1. ✅ 图片URL是否正确（可以在浏览器中直接访问测试）
2. ✅ 后端是否配置了静态资源映射（方法二和方法三）
3. ✅ 小程序中图片URL是否需要拼接完整地址
4. ✅ 网络图片是否支持跨域访问
