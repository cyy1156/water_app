# 头像与昵称改动说明

## 改动目标

- **取消「授权头像」能力**：不再使用 `chooseAvatar`、不上传头像、不依赖微信头像。
- **头像展示**：使用「首页模型图像」作为头像位置展示图，**保持现有卡片布局不变**（左侧圆形头像位 + 右侧昵称 / 等级 / 金币 / 阶段 / 经验条）。
- **昵称逻辑**：昵称由用户自行设置；首次登录时尝试获取昵称，若无昵称则随机分配一个。

---

## 一、头像改动

### 1.1 现状（待移除）

- 未登录态：圆形占位 + 「选择头像」按钮，点击触发 `open-type="chooseAvatar"`，选图后 `wx.uploadFile` 上传到后端。
- 已登录态：左侧圆形显示用户上传/微信头像 `avatarUrl`。
- 相关：`onChooseAvatar`、`onProfileChooseAvatar`、`USER_AVATAR_UPLOAD`、后端 `/user/avatar/upload` 等。

### 1.2 目标（改为首页模型图）

- **不再**使用 `chooseAvatar`、不上传头像、不请求微信头像。
- 头像位置**固定展示「首页模型图像」**：
  - 图片来源：与首页一致的模型图，建议使用 `app.globalData.agentImageUrl`（如 `https://image2url.com/r2/default/images/1771840797728-xxx.png`），或单独在 `app.js` / 常量中配置「个人页头像用图」。
- **布局完全保持**：第一张参考图布局不变——左侧圆形头像区域、右侧昵称、Lv.x、幼苗/阶段、金币、经验条（390/1000 EXP）的排布与样式均不改变，仅将头像内容从「用户头像」改为「首页模型图」。

### 1.3 涉及文件与修改点（建议）

| 位置 | 改动说明 |
|------|----------|
| `pages/profile/profile.wxml` | 头像区域改为单一 `<image>`，`src` 绑定为首页模型图 URL（如 `agentImageUrl` 或新常量），移除 `button open-type="chooseAvatar"` 及未登录态下「选择头像」按钮。 |
| `pages/profile/profile.js` | 移除 `onChooseAvatar`、`onProfileChooseAvatar`；`data` 中可保留 `avatarUrl` 用于兼容或改为 `profileAvatarUrl` 并赋值为模型图 URL；`loadMeSummary`/`applyMe` 中不再用后端返回的 `avatarUrl` 覆盖头像展示（或仅在没有配置模型图时做兜底）。 |
| `pages/home/home.wxml` / `home.js` | 若有首次登录弹窗里的头像选择，一并移除，改为仅处理昵称。 |
| 后端 | `/user/avatar/upload` 可保留但前端不再调用；若产品确定永不使用上传头像，可后续下线该接口；数据库 `user.avatar_url` 可保留作兼容或不再用于个人页展示。 |

## 二、昵称改动

### 2.1 逻辑说明

- **昵称由用户自己取**：提供入口让用户填写/修改昵称（例如输入框、弹窗输入、或设置页「修改昵称」）。
- **首次登录**：
  - 若已能获取到昵称（例如从微信 `getUserProfile`、或已有本地/后端缓存），则使用该昵称。
  - **若无昵称**（用户未授权、未填写或接口未返回）：则**随机分配一个昵称**（例如「小可爱」「小水滴」「用户xxx」等随机池或后端生成）。

### 2.2 涉及文件与修改点（建议）

| 位置 | 改动说明 |
|------|----------|
| `pages/profile/profile.js` | 首次登录/拉取用户信息后：若 `nickname` 为空或为「微信用户」等默认值，则调用「随机昵称」逻辑（前端随机池或请求后端生成），再 `PUT /user/update` 写回后端。 |
| 后端（可选） | 提供接口如 `GET /user/random-nickname` 或在校验首次登录时在服务端生成随机昵称并写库，前端只读；若前端随机即可，则仅需前端随机 + `PUT /user/update`。 |
| 个人页展示 | 保持 `{{ nickname || '小可爱' }}` 或统一为 `displayName`，确保随机分配后的昵称能正确显示在卡片右侧。 |

---

## 三、布局与交互（保持不变）

- **第一张参考图布局**：左侧圆形头像 + 右侧  
  `昵称`、`Lv.x`、`幼苗`（阶段）、金币 `225`、经验条 `390/1000 EXP`  
  的排版与样式**不做改动**，仅头像内容改为首页模型图，昵称来源改为「用户自取 + 首次登录无则随机」。
- 若存在「未登录 / 已登录」两种卡片状态，可合并为一种：始终显示上述布局，头像固定为模型图，昵称显示当前昵称或随机得到的昵称。

---

## 四、小结

| 项目 | 原逻辑 | 新逻辑 |
|------|--------|--------|
| 头像 | 授权/选择头像，上传或拉微信头像 | 固定使用「首页模型图像」，布局不变 |
| 昵称 | 依赖授权或后端返回 | 用户自己取；首次登录无昵称则随机分配 |
| 布局 | 第一张图布局 | 保持第一张图布局不变 |

按上述说明修改后，即可去掉授权头像能力，用首页模型图占位头像，并实现「昵称自取 + 首次无则随机」的逻辑。
